# Jetix Production Company

Продюсерская компания Jetix — отдельный репозиторий, заведён 10.10.2026 по его слову
«сделай новый репозиторий, назови jetix production company».

## Что это

Репозиторий продюсерского центра: собрать команду и продать услуги центра на $100k.
Здесь хранятся артефакты, которые нельзя потерять. Рабочее обсуждение идёт в чате проекта,
сюда попадает результат.

## Как устроено

```
README.md     этот файл — вход
CLAUDE.md     правила работы для агента в этом репозитории
docs/         главные артефакты и живые реестры компании
  plan/       принятый план работ по центру
  resheniya/  журнал решений
  komanda/    команда: кто, роль, условия
  zadachi/    задачи
  klienty/    клиенты и этап продажи
projects/     рабочие папки, любая новая работа — папкой здесь
  upakovka-prodyuserskogo-centra/   база: упаковка центра от 10.10 (перенесена из jetix-os)
```

## С чего начать

1. [`projects/upakovka-prodyuserskogo-centra/_index.md`](projects/upakovka-prodyuserskogo-centra/_index.md) — база: что уже сделано и что читать первым.
2. [`docs/zadachi/zadachi.md`](docs/zadachi/zadachi.md) — что сейчас в работе.
3. [`docs/resheniya/`](docs/resheniya/) — что уже решено.

## Путь документа

`projects/<имя>/` (черновик, ресёрч) → обсуждение в чате → его «да» → `docs/` (чистовик).
