# Совет извне

Заведено 20.10 по его слову: «чтобы это не потерялось — отдельную папку вот это вот в
jetix-production-company репозитории делаешь, и тогда сбор этих документов там этому человеку
на посмотреть, как бы извне».

## Зачем папка

Он упёрся в две вещи сразу: как позиционировать блог (ведущий · специалист · новостник) и на чём
зарабатывает группа независимых консультантов. Решать это угадыванием он не хочет — хочет на этой
неделе созвониться с пятью-шестью людьми, у которых есть реальный опыт бизнеса, и за час каждому
рассказать концепцию.

Папка держит пакет, с которым идут на такой час.

## Где что лежит

```
_index.md                     этот файл — вход
docs/
  01-ZAPROS.md                ⭐ §0 сырые расшифровки обоих голосовых · §1 его слово по темам ·
                              §3 что должны получить в конце + список Д-1…Д-8 · §5 слоты
  02-REESTR-REPOZITORIYA.md   ⭐ все 79 документов этого репозитория с пометкой, под какой
                              документ пакета годятся; для передачи его агенту
```

## Состояние

🔶 **Ждёт его прочтения.** Список документов Д-1…Д-8 — предложение пульта, шесть слотов для
ответа в `docs/01-ZAPROS.md` §5. После его «ок» — поиск по `jetix-os`, Notion и Miro плюс
ресёрч наружу под Д-8, дальше наполнение по шагам.

Этот репозиторий уже обойдён целиком — `docs/02-REESTR-REPOZITORIYA.md`.

## Границы

- ⛔ Notion и Miro — **потом**, его порядком. Сейчас только репозиторий.
- ⛔ Писать людям в личку и выбирать позиционирование — его рукой.

## ⚠️ Что мешает собрать пакет как есть

Рамка в документах репозитория разная: «продюсерский центр» (10.10), «консалтинговая фирма»
(12.10), «кланы и корпорация» (15.10). Без сверки собеседник увидит за один час три разных
бизнеса. Разбор — `docs/02-REESTR-REPOZITORIYA.md`, последний раздел.
