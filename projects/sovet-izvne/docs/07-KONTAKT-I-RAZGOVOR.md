# Контакт и разговор

Четвёртый документ пакета. Первые три объясняют замысел, этот — рабочий: с ним пишут шестерым,
проводят шесть часов и потом кладут ответы рядом.

Его слово 20.10: «За первые 5–10 минут разговора я могу объяснить ситуацию и свой замысел.
Основное время остаётся на обсуждение».

---

## §1 Личное сообщение — черновик

> ⛔ **Отправляет Руслан своей рукой.** Агент наружу не пишет, контакты не ищет, людей не
> называет. Ниже — заготовка, не отправленное сообщение.

Правило одно: длинное первое сообщение не читают. Четыре-шесть строк, никакой продажи, и
понятная просьба — час и совет, а не «уникальная возможность».

### Вариант А — человеку, которого знаю или читал

```text
Привет, [имя]. Я 🔶[откуда знаю: читаю тебя с …; пересекались на …; смотрел твоё …].

Я строю компанию, которая со временем объединит независимых специалистов и консультантов,
и параллельно запускаю блог с интервью. Замысел есть, с чего начать — пока нет.

Хочу попросить час. Не про деньги и не про участие — мне нужен взгляд человека, который
это уже проходил: где здесь реальная возможность, а где я усложняю.

🔶[Почему именно ты — одной фразой, конкретно: ты собрал команду с нуля; у тебя как раз
консалтинг, а не агентство; ты писал о том, что …]

Со своей стороны могу быть полезен: интервью, помощь с видео и соцсетями или конкретная
задача в твоём проекте — если тебе это интересно.

Если сейчас не время — просто скажи, без обид.
```

### Вариант Б — холодному

```text
Здравствуйте, [имя]. Меня зовут Руслан, я из Берлина. Пишу напрямую и коротко.

Я строю компанию, которая объединит независимых специалистов и консультантов, и веду блог
с интервью. Сейчас выбираю, с чего начать, и проверяю свои предположения на людях с
реальным опытом, а не угадываю.

Прошу час разговора. Мне нужен ваш взгляд со стороны: где в замысле есть возможность и
чего я не учитываю. Ничего не продаю.

🔶[Почему обращаюсь именно к вам — конкретная вещь из их опыта или текста, одна фраза.]

Взамен готов предложить интервью, помощь с видео и соцсетями или работу по конкретной
задаче в вашем проекте.

Если тема не ваша — скажите, я пойму.
```

### Что заполнить своей рукой

| 🔶 Слот | Что туда |
|---|---|
| Откуда знаю | Конкретная точка: текст, выступление, общий знакомый, площадка. Не «слежу за вами» |
| Почему именно ты | Одна вещь из его опыта, которая отвечает на мою развилку. Это единственная строка, по которой видно, что письмо не рассылка |
| Что могу взамен | Выбрать **одно** из четырёх под этого человека, не перечислять все (развёрнуто — `06-KOMU-I-S-CHEM.md`) |

Безличное сообщение видно с первой строки. Если строку «почему именно ты» заполнить нечем —
это сигнал, что человек в первую волну не идёт.

### 🔶 Каденция касаний — слот владельца

Сколько раз писать, через сколько напоминать и после какого срока считать отказом — **не
агентское решение**. Слот пустой, заполняет он.

```
Напоминание через: ____    Сколько всего касаний: ____    Считаю отказом после: ____
```

## §2 План созвона на 60 минут

| Минуты | Блок | Что происходит |
|---|---|---|
| 0–5 | Разогрев | Спасибо за время, кто я, сколько займём. Спросить разрешение записывать или помечать себе. Сразу назвать, чего прошу: взгляд со стороны, не одобрение |
| 5–13 | **Мой рассказ** | Ситуация и замысел. Что уже есть и что пока предположение — по `04-OPISANIE-IDEI.md`. Восемь минут, с таймером. Дальше молчу |
| 13–20 | Его первая реакция | Не перебивать, не защищаться, не уточнять. Первые семь минут чужой реакции — самое ценное в часе |
| 20–40 | **Развилки** | Блок приоритетных вопросов из `05-RAZVILKI-I-VOPROSY.md`. Успеть 3–4 развилки, а не все. Показывать варианты, чтобы было что сравнивать и критиковать |
| 40–50 | **Что я упускаю** | Два вопроса дословно: «что в этом замысле ты бы сделал иначе?» и «чего я не учитываю, что тебе очевидно?» |
| 50–55 | Встречное | Что ему самому интересно, нужна ли ему помощь с видео, соцсетями или задачей — по `06-KOMU-I-S-CHEM.md`. Час не должен быть просьбой в одну сторону |
| 55–60 | **Что дальше** | Договорённость на конкретный следующий шаг с датой. Без неё разговор обнуляется |

✅ **Сведено с `05-RAZVILKI-I-VOPROSY.md` (20.10):** блок 20–40 ведётся по вопросам **1–7**
(обязательные, §2 того документа), блок 40–50 — по вопросам **5, 6, 7**. Вопросы 8–13 — запас,
если собеседник разговорчив. Старая заметка ниже оставлена для истории.

Нумерация вопросов в блоке 20–40 берётся из `05-RAZVILKI-I-VOPROSY.md` — сверить перед первым
созвоном и вписать номера сюда.

### Заметки ведущему

- **Уходит в сторону** — не обрывать сразу, дать две минуты: иногда это и есть ответ. Потом
  вернуть одной фразой: «понял, а если вернуться к [развилка] — что бы ты сделал?»
- **Разносит замысел** — не спорить. Записывать дословно и копать: «что именно сломается
  первым?», «ты это видел, или так кажется?». Разнос — лучший исход часа, вежливость — худший.
- **Как не спорить** — на любое «это не сработает» отвечать вопросом, а не аргументом. Правило:
  я не защищаю замысел, я его проверяю. Пояснять только факты, если человек понял неверно.
- **Вопросы по одному.** Два вопроса подряд дают ответ только на второй.
- **Тишина после вопроса** — не заполнять. Пять секунд паузы вытягивают больше, чем ещё вопрос.
- **Не предлагать участие в первом разговоре.** Если он сам заговорит — слушать и фиксировать.

## §3 ⭐ Шаблон записи — один на каждый разговор

Заполнять **сразу после созвона, за 10 минут**, пока помнится. Поля одинаковые у всех шести —
иначе сопоставить не получится. Копия на каждого человека.

```text
РАЗГОВОР №__ · дата ____ · длительность ____

Кто
  Имя/как записал:
  Откуда знаю:
  Чем именно полезен его опыт:

Главное одной фразой
  (что я унёс из этого часа, если забуду всё остальное)

Ответы по развилкам — коротко, своими словами
  Р-1 с чего начать деятельность:
  Р-2 кто первый — клиент, специалист или публичный эксперт:
  Р-3 за что будут платить:
  Р-4 зачем опытному подключаться:
  Р-5 направление блога:
  Р-6 под какой вывеской выходить:
  (развилки и варианты — 05-RAZVILKI-I-VOPROSY.md §1)

Что я усложняю / что он убрал бы
  Что я не учитываю (его словами)
  Что, по его мнению, сломается первым

Как бы он сделал это иначе
  (его вариант реализации, даже если звучит странно)

⭐ 2–3 дословные цитаты
  «
  «
  «

Встречное
  Что ему самому интересно:
  Просил ли о чём-то:
  Готов ли к продолжению (да / нет / не ясно):

Договорённость
  Следующий шаг:
  Дата:
  За кем ход:

Моя оценка
  Польза часа: 1 / 2 / 3
  Хочу ли продолжать с этим человеком: да / нет / позже
  Что я сделаю иначе в следующем разговоре:
```

Если на заполнение уходит больше десяти минут — поле лишнее, вычеркнуть. Форма, которую лень
заполнять, обнуляет весь пакет.

## §4 Сводная таблица шести разговоров

Одна строка — один человек. Заполняется по мере разговоров. Смотреть на **столбцы**: там, где
три и более ответов сходятся, и есть повторяющееся замечание.

| 1 | | | | | | | | | |
| 2 | | | | | | | | | |
| 3 | | | | | | | | | |
| 4 | | | | | | | | | |

## §5 Что делать после шести разговоров

Его требование: «После нескольких разговоров я могу сопоставить ответы, увидеть повторяющиеся
замечания и выбрать конкретную гипотезу для проверки на ближайший месяц: что предложить, кому и
как проверить интерес».

Один заход на час-полтора, после шестого разговора:

1. **Прочитать столбцы, не строки.** По каждой развилке выписать, что сказали шестеро.
2. **Отметить совпадения.** Три и более одинаковых ответа — это сигнал. Один яркий ответ — это
   мнение, даже если он самый убедительный.
3. **Отдельно выписать то, что сказали независимо друг от друга и чего не было ни в одном нашем
   документе.** Это и есть то, ради чего затевался пакет.
4. **Сформулировать одну гипотезу** по четырём строкам:

```text
Гипотеза на месяц
  Что предлагаю:
  Кому (один сегмент, не три):
  Как проверю интерес (действие, а не опрос):
  Признак, что гипотеза не подтвердилась:
  Срок проверки:
```

5. **Выбор гипотезы — его.** Агент сводит таблицу и показывает совпадения; какую гипотезу брать
   на месяц, решает он.
