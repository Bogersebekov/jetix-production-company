# Инструкция локальному агенту: Продюсерский центр в Jetix PM

Для агента Claude Code на компьютере Руслана (Windows, хранилище `D:\private`). Написана
2026-10-10 облачным Claude из проекта «Продюсерский центр». Почему так: [`rabochee-mesto.md`](rabochee-mesto.md),
разбор плагина: [`razbor-plagina.md`](razbor-plagina.md).

## Цель

Перенести работу продюсерского центра из ClickUp в Obsidian на плагине Jetix PM в том же виде:
проект «Продюсерский центр», разделы Команда / Клиенты / Сайт / Блог, карточки `П-N. …` со
сроками, зависимостями и документами. Плюс главный экран («командный центр»), откуда добавить
задачу и зайти в любой раздел. Работа отделена от личных заметок.

## Правила

  не руками в frontmatter.

## Шаг 1. Репозиторий компании внутри хранилища

```bash
cd /d/private/3-work
git clone https://github.com/Bogersebekov/jetix-production-company.git
echo "/3-work/jetix-production-company/" >> /d/private/.gitignore
```

- Проверь, что private больше не видит эту папку: `git -C /d/private status` чист по ней.
- Проверь в Obsidian, что папка появилась в дереве файлов.
- Синхронизация (если Руслан согласился): скрипт `D:\private\tools\sync-company.ps1`, который в
  папке репозитория делает `git pull --rebase --autostash`, затем, если есть изменения в `pm/`,
  `git add pm && git commit -m "[pm] правки из Obsidian" && git push`. Задача в Планировщике
  Windows раз в 15 минут. Покажи скрипт Руслану до включения.

## Шаг 2. Доработка календаря (спроси)

В репозитории плагина открыт черновой PR №1 «Create time entry: задача подставляется сама»:
https://github.com/Bogersebekov/obsidian-jetix-pm/pull/1. Окно «Create time entry» теперь само
подставляет задачу: из блока плана под отрезком, иначе «— общее» задачу проекта блока, иначе
последнюю задачу с учётом времени.

1. Перед этим запушь незапушенные коммиты `jetix-main`, если они есть и Руслан согласен.
2. `git fetch origin && git checkout claude/project-thread-0q5gi3`, затем `bash scripts/build.sh`,
   `./node_modules/.bin/vitest run`, `node scripts/install-to-vault.mjs D:/private`, перезагрузи плагин.
3. Покажи Руслану: выдели отрезок в календаре поверх блока плана → Create time entry.
   Задача должна стоять сразу, с подсказкой «по плану: …».
4. Если ему нравится — смерджи PR в `jetix-main` по его слову.

## Шаг 3. Проекты

1. В настройках Jetix PM временно поставь «Projects folder» = `3-work/jetix-production-company/pm`

## Шаг 4. Задачи

**Откуда брать.**
- Пункты плана П-1 … П-12: `projects/plan-100k/docs/plan.md` в репозитории компании
  (П-1, П-2, П-3, П-6 решены 2026-10-10 → `done`).
- Живой список: `docs/zadachi/zadachi.md` (П-6, П-9, П-11, П-12 со сроками и ссылками на ClickUp).
- Все карточки ClickUp (около 26, из них 17 рабочих задач на 11.10) и их зависимости есть только
  в ClickUp: папка «Продюсерский центр» в Team Space. Прочитай их коннектором ClickUp, если он у тебя
  есть, по одному запросу на список (бесплатный тариф даёт ~100 действий в день), либо попроси
  Руслана выгрузить списки. Не выдумывай задачи, которых нет в источниках.

**Как переносить.**

| ClickUp | Jetix PM |
|---|---|
| список Команда / Клиенты / Сайт / Блог | подпроект с тем же именем |
| имя карточки `П-N. …` | `title` без изменений |
| статус to do / in progress / ждёт / complete | `todo` / `in-progress` / `blocked` / `done` |
| срок, дата начала | `due`, `start` (`YYYY-MM-DD`) |
| waiting on | `dependencies` (id задачи-блокера) |
| документ, привязанный комментарием | ссылка в описании задачи на файл в репозитории компании |
| исполнитель | `assignees` (заметка человека) |

1. Первый проход: создай все задачи (`POST /v1/projects/{id}/tasks`), запиши соответствие
   «карточка ClickUp → id задачи».
2. Второй проход: зависимости `PATCH /v1/tasks/{id}` с `dependencies`.
3. Документы. Восемь документов ClickUp: Команда на старт, Блог: темы, Клиенты: портреты,
   Предложение Антону, Инструменты монтажа, Блог: упаковка, Референсы сайта, Решения и план.
   Копии части из них уже в репозитории: `projects/plan-100k/docs/` (план, решения, `research/`),
   `docs/komanda/README.md`. Каких нет — выгрузи из ClickUp в `projects/plan-100k/docs/` и закоммить
   в репозиторий компании.
4. Сверка: число задач в каждом разделе равно числу карточек в списке ClickUp; Гант
   «Продюсерского центра» с подпроектами показывает стрелки зависимостей.

## Шаг 5. Главный экран

1. Поставь плагины **Homepage** и **Meta Bind** (Settings → Community plugins). Спроси Руслана
   перед установкой.
2. Заметка `3-work/jetix-production-company/pm/Командный центр.md`:
   - кнопки Meta Bind, каждая запускает команду: `jetix-pm:new-task` (➕ Задача),
     `jetix-pm:jetix-start-work` (▶ Начать работу), `jetix-pm:jetix-create-time-entry` (⏱ Записать факт).
     Точные id проверь: `obsidian vault=private commands | grep jetix-pm`;
   - ссылки на заметки проектов: Продюсерский центр, Команда, Клиенты, Сайт, Блог;
   - встроенные виды из `pm/Командный центр.base` (скопируй за основу
     `tools/vidy/tasknotes/tasks-default.base`, отфильтруй по папке `3-work/jetix-production-company/pm`):
     «Сегодня и просрочено» (срок ≤ сегодня, не done/cancelled), «В работе» (`in-progress`),
     «Ждут» (`blocked`), канбан по статусам.
3. Homepage: открывать «Командный центр» при запуске.
4. Проверь в Obsidian каждую кнопку и каждый вид, сделай скриншот для Руслана.
