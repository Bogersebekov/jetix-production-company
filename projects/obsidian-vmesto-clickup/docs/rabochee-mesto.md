# Рабочее место в Obsidian: главный экран и репозитории

Дата: 2026-10-10. Ответ на запрос Руслана: командный центр как в ClickUp, работа отдельно от
личного, как связать репозитории. Инструкция для локального агента по настройке:
[`instrukciya-agentu.md`](instrukciya-agentu.md).

## 1. Главный экран

Что уже есть в Jetix PM (проверено по коду):

- **Панель проектов** (`Open projects pane`): список всех проектов.
- **Обзор проекта**: прогресс, вехи, подпроекты, свойства. Это и есть страница проекта
  «Продюсерский центр», а Команда, Клиенты, Сайт и Блог — его подпроекты, у каждого свой обзор,
  таблица, Гант и канбан. Гант можно открыть по проекту вместе со всеми подпроектами.
- **Виды Bases** твоего форка: список задач, канбан, календарь, мини-календарь. Их можно
  встраивать в обычную заметку.

Чего нет: одного экрана, где сразу видно «что горит сегодня», есть кнопка «добавить задачу» и
вход в разделы. Собираем его без кода, из двух готовых плагинов:

| Что | Чем |
|---|---|
| Открывать главный экран при запуске Obsidian | плагин **Homepage** |
| Кнопки «➕ Задача», «▶ Начать работу», «⏱ Записать факт» | плагин **Meta Bind** (кнопка запускает команду Jetix PM) |
| Блоки «Сегодня и просрочено», «В работе», «Ждут» | `.base` файлы с видом `jetixTaskList` / `jetixKanban`, встроенные в заметку |
| Вход в Продюсерский центр и четыре раздела | ссылки на заметки проектов (открываются обзором) |

Как это выглядит:

```
Командный центр
[➕ Задача] [▶ Начать работу] [⏱ Записать факт]

Продюсерский центр →   Команда · Клиенты · Сайт · Блог

Сегодня и просрочено   (список задач со сроком ≤ сегодня)
В работе               (статус in-progress)
Ждут                   (статус blocked)
```

Если через пару недель этого окажется мало, следующий шаг — свой вид «Командный центр»
внутри плагина. Сейчас писать его рано.

## 2. Работа отдельно от личного

Сейчас всё в одном хранилище `D:\private`: задачи, мысли, скиллы агента. Варианты:

| | Как | Плюсы | Минусы |
|---|---|---|---|
| **А. Навести порядок в private** | одно хранилище, одна папка `3-work/` под работу, остальное — личное | ничего не меняется в git и синхронизации | я из облака до задач не дотягиваюсь; каша лечится только дисциплиной |
| **Б. Отдельное хранилище = репозиторий компании** | `jetix-production-company` открывается в Obsidian как своё хранилище со своим Jetix PM | полное разделение; я пишу задачи прямо в git | два календаря и два таймера: факт по работе и личный учёт времени расходятся по разным хранилищам |
| **В. Репозиторий компании папкой внутри private** (рекомендую) | клон `jetix-production-company` лежит в `D:\private\3-work\jetix-production-company`, private его игнорирует в git | один Obsidian, один календарь, один таймер и журнал дня; работа компании в своём репо, отдельно от личного; я пишу туда из облака, у тебя подтягивается | нужно автоподтягивание этой папки (скрипт раз в 15 минут или агент в начале дня) |

**Стратегическое против ежедневного.** Стратегия, мысли, личные решения остаются в private.
Проекты компании, их задачи и документы живут в репозитории компании. Ежедневные задачи,
которые ты решаешь с агентами «по методу дня», — это задачи проектов: они идут в тот проект,
к которому относятся, а личные в Inbox private. Отдельный третий репозиторий под
«рабочее» не нужен: рабочее — это и есть репозиторий компании.

`jetix-os` (система управления, правила дома) остаётся как есть.
