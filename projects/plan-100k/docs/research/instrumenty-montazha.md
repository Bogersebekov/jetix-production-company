# Инструменты для блога: монтаж и продакшн-воркфлоу

Цены проверены 2026-10-10 на офсайтах (USD, без налогов; в Германии итог в EUR может отличаться). «Не нашёл» — значит, на официальной странице подтверждения нет.

**Рекомендация (старт за 0–20 $/мес):**
1. Сейчас: CapCut Free (desktop + телефон), снимать и монтировать shorts самому. Русские субтитры проверить на первом ролике. Если не устроят, Submagic Starter ($12–19).
2. Для длинного YouTube: DaVinci Resolve Free; из длинных роликов делать shorts через OpusClip Free.
3. Когда появится монтажёр: отдавать ему исходники + сценарий, монтирует в Premiere или Resolve (что у него есть). Descript не брать, русского нет.

## 2. Продакшн-воркфлоу (идея → сценарий → съёмка → монтаж → публикация)

| Вариант | Цена | Плюсы | Минусы |
|---|---|---|---|
| **ClickUp** + шаблон [Modern Social Media Calendar](https://clickup.com/templates/modern-social-media-calendar-t-205387707) ([подборка шаблонов](https://clickup.com/blog/content-calendar-templates/)) | Free Forever; платные от $7–10/польз./мес ([pricing](https://clickup.com/pricing): на странице две сетки цен, уточнить при покупке) | Уже рабочий инструмент; статусы, календарь, поля (канал, дата, хэштеги); задачи монтажёру с дедлайнами; Docs под сценарии; один вход для команды | Писать длинные сценарии менее удобно, чем в редакторе заметок; шаблон надо подогнать под видео-пайплайн |
| [Notion](https://www.notion.com/pricing) | Free; Plus $10/место/мес | Красивые базы и календари, много готовых шаблонов | Ещё один инструмент рядом с ClickUp: задачи разъедутся |
| Obsidian (папка) | Бесплатно | Удобно писать идеи и сценарии, всё локально в Markdown | Нет нормального календаря, статусов и совместной работы с монтажёром; смешивается с личной жизнью, хотя Руслан решил держать работу в ClickUp |
| Отдельные сервисы (Later, Buffer, Metricool и т.п.) | Цены не проверял | Автопостинг и аналитика по соцсетям | Пока избыточно; подключать, когда будет регулярный поток публикаций |

Скелет пайплайна в ClickUp: список «Контент» → статусы `Идея → Сценарий → Готово к съёмке → Снято → Монтаж → На проверке → Запланировано → Опубликовано`; поля: Площадка (IG/TikTok/YT Shorts/YT long), Формат (short/long), Дата публикации, Ссылка на исходники, Ссылка на пост; вид Calendar + Board; сценарий — в описании задачи или в ClickUp Doc.

Если всё же папка в Obsidian (только черновики идей):
```
Content/
  00-inbox/        сырые идеи
  01-scripts/      сценарии, 1 файл = 1 ролик (YYYY-MM-DD-тема.md)
  02-published/    архив + ссылки на посты
  templates/       шаблон сценария (хук, тезисы, CTA)
```

**Рекомендация (старт за 0–20 $/мес):**
1. Весь пайплайн и календарь — в ClickUp на Free: взять шаблон Social Media Calendar и подогнать статусы под видео.
2. Obsidian для контента не заводить. Если в Obsidian приходит идея, переносить её в «Идеи» в ClickUp.
3. Планировщик постов (Later/Buffer/Metricool) — позже, когда будет 3+ публикаций в неделю.
