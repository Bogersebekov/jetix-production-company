Как синхронизировать:

- Истина — репозиторий. ClickUp — окно для ежедневной работы и для команды, когда она появится.
- Одна задача — одна карточка. Имя карточки начинается с номера пункта плана (`П-6. …`), по нему
  агент находит её в ClickUp.
- Решение по пункту: агент пишет его в `docs/resheniya/` и `plan.md`, затем комментарием в
  карточку и меняет её статус. Новая задача: строка в `zadachi.md`, затем карточка в нужном
  списке и ссылка на неё в колонке ClickUp.
- Если Руслан двигает карточку в ClickUp сам, агент в начале сессии сверяет статусы и переносит
  изменения в `zadachi.md`.
