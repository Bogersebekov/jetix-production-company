# docs/ — главные артефакты компании

Здесь лежит то, что нельзя потерять: принятые документы и живые реестры компании.
Черновики, ресёрч и рабочие заходы живут в `projects/<имя>/`, обсуждение — в чате проекта.

| Папка | Что |
|---|---|
| `plan/` | принятый план работ по центру |
| `resheniya/` | журнал решений Руслана с датой и источником |
| `komanda/` | кто в команде, роль, условия, статус |
| `zadachi/` | живой список задач |
| `klienty/` | клиенты и этап продажи |

Документ попадает в `plan/`, когда Руслан сказал по нему «да». Реестры (решения, команда,
задачи, клиенты) ведутся здесь сразу.
